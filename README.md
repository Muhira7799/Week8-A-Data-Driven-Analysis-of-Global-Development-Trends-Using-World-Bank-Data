# Digital Connectivity and Internet Adoption in Africa (2010–2024)

## Project Overview

This project analyzes digital connectivity and internet adoption across 54 African countries from 2010 to 2024.

The project uses World Development Indicators (WDI) data from the World Bank and focuses on three main indicators:

- Internet Users (%)
- Mobile Subscriptions
- Fixed Broadband

The analysis was performed using Python and Power BI to identify trends, relationships, country differences, and important digital connectivity insights.

---

## Objective / Problem Statement

The main objective of this project is to understand the development of digital connectivity and internet adoption across African countries.

The project aims to:

- Analyze changes in internet usage over time.
- Compare digital connectivity between countries.
- Examine relationships between internet users, mobile subscriptions, and fixed broadband.
- Identify important trends and changes.
- Identify areas where further digital development may be needed.
- Provide recommendations to support digital development and decision-making.

---

## Dataset Description

The dataset used in this project is the World Development Indicators (WDI) dataset provided by the World Bank.

The selected data covers:

- **Countries:** 54 African countries
- **Years:** 2010–2024
- **Indicators:** 3
- **Final observations:** 2,430

### Selected Indicators

1. **Internet Users (%)**  
   Percentage of individuals using the Internet.

2. **Mobile Subscriptions**  
   Mobile cellular subscriptions per 100 people.

3. **Fixed Broadband**  
   Fixed broadband subscriptions per 100 people.

## Analysis Methodology

The following analytical techniques were applied:

### 1. Trend Analysis

Yearly averages were calculated for Internet Users, Mobile Subscriptions, and Fixed Broadband to identify changes between 2010 and 2024.

### 2. Correlation Analysis

Correlation analysis was used to examine relationships between the three connectivity indicators.

### 3. Year-to-Year Change Analysis

Annual changes were calculated to identify significant increases and decreases in connectivity indicators.

### 4. KPI Analysis

Key Performance Indicators were calculated for:

- Average Internet Users
- Average Mobile Subscriptions
- Average Fixed Broadband
- Average Digital Connectivity Score

### 5. Country Comparison

Countries were compared based on their average digital connectivity indicators.

---

## Key Findings

The analysis produced several important findings:

- Average Internet Users increased from **9.05% in 2010** to **44.89% in 2024**.
- Average Mobile Subscriptions increased from **54.74 per 100 people** in 2010 to **107.25 per 100 people** in 2024.
- Average Fixed Broadband increased from **0.72 per 100 people** in 2010 to **4.33 per 100 people** in 2024.
- Mobile connectivity remained much higher than fixed broadband.
- Morocco recorded the highest average Internet Users rate in the country comparison, at approximately **69.11%**.
- Internet Users and Mobile Subscriptions had the strongest correlation, at approximately **0.69**.

---

## Insights

The analysis shows significant improvement in digital connectivity across the selected African countries between 2010 and 2024.

However, important differences remain between countries.

Mobile connectivity is the dominant form of digital access, while fixed broadband adoption remains relatively low.

The results also indicate that a significant proportion of the population remained offline in 2024, showing that the digital divide is still an important development challenge.

---

## Recommendations

Based on the findings, the following recommendations are proposed:

1. Invest in affordable and reliable broadband infrastructure.
2. Expand internet access in rural and underserved areas.
3. Improve mobile network coverage, quality, and affordability.
4. Reduce the cost of internet services and data packages.
5. Strengthen digital literacy and digital skills programs.
6. Use digital connectivity data to support investment and policy decisions.
